术语					含义
变量 (Variable)		存数据的盒子，如 num = 5
input()				从终端接收用户输入，返回值始终是字符串
int()					将字符串/浮点数转换为整数
if / elif / else			条件分支判断链，从上往下匹配，命中即停
while				条件为 True 时反复执行的循环
break				立即跳出当前循环
continue				跳过本轮循环剩余代码，直接进入下一轮
pass	空占位符，		什么都不做，用来填满语法要求的代码块
f-string				格式化字符串，f"..." 中用 {} 嵌入变量
def					定义函数
return				函数的输出值；执行到 return 立即结束函数
形参 / 实参			定义函数时括号里的是形参，调用时传进去的是实参
None				Python 的"空值"，表示"什么都没有"
